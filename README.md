# Vasu — музыкальный каталог на Django

Веб-приложение для хранения и прослушивания музыки. В нём можно вести каталог жанров, исполнителей и треков, загружать аудиофайлы и фотографии исполнителей и слушать треки прямо на странице.

## Возможности

- **Жанры:** название на русском и английском, описание
- **Исполнители:** имя или название группы, фотография
- **Треки:** название, длительность, исполнитель, несколько жанров, аудиофайл со встроенным плеером
- **Фильтрация** списка треков по исполнителю
- **Формы добавления** для всех сущностей с проверкой данных (Django ModelForm)
- **Админ-панель** Django для управления данными

## Модель данных

```
Genre (жанр)          Artist (исполнитель)
   ▲                       ▲
   │ многие-ко-многим      │ многие-к-одному
   └──────── Track (трек) ─┘
```

- `Genre`: `name_ru`, `name_en` (уникальные), `description`
- `Artist`: `name` (уникальное), `image`
- `Track`: `title`, `duration` (в секундах), `genres` → Genre, `artist` → Artist, `audio_file`

Удалить исполнителя, у которого есть треки, нельзя (`on_delete=RESTRICT`). Так в базе не остаются треки без автора.

## Структура проекта

```
Vasu/
├── manage.py
├── music/          # настройки проекта (settings, urls, wsgi/asgi)
├── main/           # приложение: модели, формы, представления, маршруты, миграции
├── templates/      # HTML-шаблоны страниц
└── media/          # загруженные аудиофайлы и изображения
```

## Страницы

| Адрес | Что делает |
| --- | --- |
| `/` | Главная |
| `/genres/` | Список жанров |
| `/genres/create/` | Добавление жанра |
| `/artists/` | Список исполнителей |
| `/artists/create/` | Добавление исполнителя |
| `/tracks/` | Список треков с плеером и фильтром по исполнителю |
| `/tracks/create/` | Добавление трека |
| `/admin/` | Админ-панель Django |

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/vasil-zvere/Vasu.git
   cd Vasu
   ```
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv env
   # Windows
   env\Scripts\activate
   # Linux / macOS
   source env/bin/activate
   ```
3. Установите зависимости:
   ```bash
   pip install django pillow
   ```
4. Примените миграции и запустите сервер:
   ```bash
   python manage.py migrate
   python manage.py runserver
   ```
5. Откройте в браузере http://127.0.0.1:8000/

Чтобы войти в админ-панель, создайте суперпользователя: `python manage.py createsuperuser`.
